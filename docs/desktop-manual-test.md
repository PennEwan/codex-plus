# 桌面 App 手动测试清单

目标：在官方 Codex 桌面 App（26.1013.4894.0，内核 0.163.0-alpha.10.2）中验证四个验收场景，并观察 CLI 实测无法覆盖的 UI 表现。

## 前置条件
- 双击 `记录状态.cmd`，应看到：
  - `状态：● 正在记录`
  - `插件 Hook：已加载 12 个；trusted 12`
- 开发阶段记录范围限定为 `D:\ctr-testbed`，因此请在 App 中 **打开文件夹 `D:\ctr-testbed`** 新建会话。

## 步骤（同一个会话内依次进行）

| # | 操作 | 需要你观察并记下 |
|---|---|---|
| 1 | 发送：`用一句话介绍 JSONL 文件。` | 第一条消息后是否出现「● Codex Task Recorder 正在本地记录本会话」提示？出现在哪里、什么样式？有没有 Hook 报错提示？ |
| 2 | 发送：`请运行 echo desk-ok 和 desk-no-such-cmd 两个命令，并报告结果。` | 是否弹出命令审批？回复是否明显变慢？ |
| 3 | 在输入框的模型选择器里 **切换到另一个模型**（例如 GPT-5.5），发送：`用一句话复述上一步结果。` | — |
| 4 | 发送：`请运行 ping -n 90 127.0.0.1，结束后总结输出。` 命令开始运行后 **点击停止按钮**。 | 停止是否正常？有没有 Hook 相关提示？ |
| 5 | 双击 `停止记录.cmd`，然后在同一会话发送：`ok`。之后双击 `开始记录.cmd` 恢复。 | — |
| 6 | （可选）在 **其他文件夹** 新建会话发一条消息。 | 应当不被记录（开发阶段范围限定）。 |

完成后告诉我，我会运行 `ctr report` 生成覆盖率报告，并把桌面端结果并入 `docs/hooks-support.md`。
